# Code of Conduct

Footprinter is a small open-source project. The expectations are simple:

- Be respectful in issues, PRs, and discussions.
- Focus on the technical work. Disagreement is fine; personal attacks and harassment are not.
- Assume good faith. Give and receive feedback constructively.

This applies to project spaces: issues, PRs, discussions, and any official project communication channels.

If someone's behavior is making the project worse, report it to hello@swellcity.ai. Reports will be handled privately. Consequences range from a private warning to a permanent ban, depending on severity.

Maintainer discretion applies.
